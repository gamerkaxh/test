/approved
Implementation design decision needs to be made to determine the best approach for populating placeholders in the prompt text. For example the prompt text may require input from the client i.e. the SIS Summary text, but it may also require additional metadata from the Knowledge Base i.e. Serial Number Prefix, Rollup Key, etc. Gen AI service and Prompts need to agree on how to do the substitution. Ideally Gen AI service would fail if prompt substitution fails.
 
prompt schema
AI Context API will allow the request to specify the prompt versions for each type (human/system) only when the AI context object is approved = false. If approved = true then the api will return the latest approved prompt versions for the given prompt names. It is assumed that a prompt is not set to approved unless it has been fully tested with an AI context.

  version NUMERIC(2, 1) NOT NULL UNIQUE, -- Unique constraint
  input TEXT[],
  approved BOOLEAN,
  text TEXT
);
